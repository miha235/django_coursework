# Курсовая работа 6: Основы веб-разработки на Django

## Описание проекта

Цель проекта — создание веб-сервиса для управления рассылками, администрирования и получения статистики, а также доработка системы с добавлением функционала блога и разделением прав доступа.

## Функциональность

### Часть 1: Разработка сервиса

1. **Управление рассылками и клиентами (CRUD):**
   - Управление клиентами (email, ФИО, комментарии).
   - Настройка рассылок (дата, время, периодичность, статус).
   - Создание и редактирование сообщений (тема, текст).

2. **Скрипт рассылки:**
   - Периодические задачи через `Django-crontab` или `apscheduler`.
   - Устойчивость к ошибкам внешнего сервиса.

3. **Интерфейс:**
   - Интуитивно понятный дизайн с использованием Bootstrap.

### Часть 2: Доработка сервиса

1. **Разделение прав доступа:**
   - **Пользователь:** управление своими данными.
   - **Менеджер:** просмотр всех данных, блокировка пользователей.

2. **Расширение модели пользователя:**
   - Регистрация с подтверждением по email.
   - Реализация интерфейса входа и регистрации.

3. **Функциональность блога:**
   - Публикация статей с заголовками, содержимым, изображениями и количеством просмотров.

4. **Главная страница:**
   - Статистика рассылок.
   - Список случайных статей из блога.

5. **Кеширование:**
   - Настройка кеширования для оптимизации работы.

6. **Переменные окружения:**
   - Вынос конфиденциальных данных в `.env` файл.

## Установка и настройка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL репозитория>
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте переменные окружения:
   - Создайте файл `.env` и добавьте необходимые параметры (пример в `.env.example`).

4. Выполните миграции базы данных:
   ```bash
   python manage.py migrate
   ```

5. Создайте суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
